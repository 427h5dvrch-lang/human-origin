# Guide testeur — HumanOrigin 0.1.26

> Build de test interne. Merci de suivre les étapes dans l'ordre.
> N'utilisez **aucun document confidentiel** : un PDF neutre est fourni.

## Ce que fait HumanOrigin
HumanOrigin **enregistre localement des périodes de travail et les relie à une version précise d'un document**. Le but est de créer un **dossier HumanOrigin relié à votre version finale** : votre PDF avec un cartouche + une preuve locale signée.

On veut votre **ressenti** sur la clarté du parcours, pas une performance.

## 1. Installer
1. Ouvrez **`HumanOrigin_0.1.26_aarch64.dmg`** (double-clic).
2. Glissez **HumanOrigin** dans le dossier **Applications**.
3. Ouvrez **HumanOrigin** depuis Applications.
   - Au 1er lancement, si macOS hésite : **clic droit sur l'app → Ouvrir**.

## 2. Autoriser (macOS)
HumanOrigin a besoin de deux autorisations pour **mesurer un travail** :
- **Accessibilité**
- **Surveillance de l'entrée**

Accordez-les si macOS le demande (Réglages Système → Confidentialité et sécurité). Sans elles, l'observation ne peut pas mesurer votre activité.

> Après avoir accordé les autorisations macOS, il peut être nécessaire de fermer puis rouvrir HumanOrigin.

## 3. Ouverture
**L'application s'ouvre directement sur le parcours de test.** Il n'y a rien à activer.

## 4. Choisir un document
- Cliquez **« 1. Choisir un document »** → sélectionnez le **PDF neutre fourni** (celui que vous allez produire ou finaliser).

## 5. Préparer le document
- Cliquez **« 2. Préparer ce document »**.

## 6. Démarrer l'observation
- Cliquez **« 3. Démarrer l'observation »**.

## 7. Travailler et enregistrer votre version finale
Pendant l'observation :
- **Travaillez dans votre application habituelle** pendant 2 à 3 minutes, de façon continue.
- **Enregistrez la version finale de votre document** avant de terminer (par exemple une courte annotation puis ⌘S dans Aperçu).

> L'idée n'est **pas** de « modifier un PDF pour débloquer un bouton » : vous **produisez / finalisez votre document pendant une période observée**. HumanOrigin relie cette période à la version finale enregistrée.

## 8. Terminer l'observation
- Cliquez **« 4. Terminer cette période de travail »**.

## 9. Créer le document HumanOrigin
- Cliquez **« 5. Créer mon document HumanOrigin »**.

### Si « Créer » n'est pas encore disponible
Ce n'est **pas forcément un bug**. Pour créer, HumanOrigin doit avoir **observé une période de travail suffisante** et le document doit avoir été **enregistré dans sa version finale**.
Si vous voyez le message **« Pas encore prêt à créer »** : continuez à travailler quelques minutes, enregistrez votre document, puis lancez ou terminez une nouvelle observation.

## 10. Écran de succès
- Titre : **« Votre document HumanOrigin est prêt »**.
- Action principale : **« Partager le dossier HumanOrigin »** → **c'est ce dossier complet qu'il faut m'envoyer** (pas seulement une capture d'écran).
- Secondaires : **« Ouvrir le PDF labellisé »**, **« Voir les détails du travail enregistré »**.

## 11. Le cartouche (bas du PDF)
Sur le PDF final, un cartouche affiche :
- « Travail observé avec HumanOrigin »
- « Des périodes de travail ont été enregistrées localement »
- « et reliées à cette version du document. »
- « Scannez pour vérifier les détails. »
- « ID preuve : … »

**Ce que cela ne signifie pas** : HumanOrigin **ne détecte pas l'IA**, **ne prouve pas l'auteur unique**, **ne certifie ni l'originalité ni la vérité du contenu**.

## 12. Envoyer votre retour
Partagez le **dossier HumanOrigin complet** et remplissez la **checklist de retour** fournie. Merci !

---
