# Guide testeur — HumanOrigin Alpha 0.1.24

> Version **Alpha** (test interne). Merci de suivre les étapes dans l'ordre.
> N'utilisez **aucun document confidentiel** : un PDF neutre est fourni.

## Objectif du test
Vérifier que le parcours est **clair et fluide** : préparer un document, l'observer pendant que vous travaillez, puis créer un **document HumanOrigin** (PDF avec un cartouche + une preuve locale signée). On veut votre ressenti, pas une performance.

## 1. Installer
1. Ouvrez le fichier **`HumanOrigin_0.1.24_aarch64.dmg`** (double-clic).
2. Glissez **HumanOrigin** dans le dossier **Applications**.
3. Ouvrez **HumanOrigin** depuis Applications.
   - Au 1er lancement, si macOS hésite : **clic droit sur l'app → Ouvrir**.

## 2. Autoriser (macOS)
HumanOrigin a besoin de deux autorisations pour **mesurer un travail** :
- **Accessibilité**
- **Surveillance de l'entrée**

Accordez-les si macOS le demande (Réglages Système → Confidentialité et sécurité). Sans elles, l'observation ne peut pas mesurer votre activité.

> Après avoir accordé les autorisations macOS, il peut être nécessaire de fermer puis rouvrir HumanOrigin.

## 3. Activer le mode Alpha
Sur l'écran d'accueil :
1. **Cliquez 5 fois rapidement** sur le titre **« HumanOrigin »**.
2. Un petit bouton **« Accès Alpha »** apparaît en bas.
3. Cliquez **« Accès Alpha »**.

*(Pour revenir à l'écran classique plus tard : bouton **« Retour au mode classique »** en bas de l'écran Alpha.)*

## 4. Choisir un document
- Cliquez **« 1. Choisir un document »** → sélectionnez le **PDF neutre fourni**.

## 5. Préparer le document
- Cliquez **« 2. Préparer le document »**.

## 6. Démarrer l'observation
- Cliquez **« 3. Démarrer l'observation »**.

## 7. Travailler ET modifier le document
Pendant l'observation :
- **Travaillez pendant 2 à 3 minutes de façon continue ou soutenue** (tapez du texte quelque part), puis **modifiez légèrement le PDF et enregistrez-le.** Exemple simple :
  1. Ouvrez le PDF dans **Aperçu**.
  2. Barre d'outils d'annotation → ajoutez **une courte ligne de texte** ou une annotation.
  3. **Enregistrez** (⌘S).

> Cette modification est **nécessaire** : elle permet à HumanOrigin de voir que le document a évolué pendant l'observation.

## 8. Terminer l'observation
- Cliquez **« 4. Terminer l'observation »**.
- L'écran indique combien d'observations sont enregistrées.

## 9. Créer le document HumanOrigin
- Cliquez **« 5. Créer mon document HumanOrigin »**.
- Écran de succès : **« Document HumanOrigin créé — preuve locale signée »**.

## 10. Ouvrir le résultat
- **Ouvrir le PDF** : le document avec un **cartouche** en bas (HumanOrigin, travail observé, ID court, QR).
- **Ouvrir le dossier** : contient le PDF et les fichiers de preuve.
- **Vérification** : ouvre la page de vérification (facultatif).

## 11. Envoyer votre retour
Remplissez la **checklist de retour** fournie et renvoyez-la. Merci !

---

**Rappel** : HumanOrigin **mesure un travail observé** et rend visible un **processus de travail**. Il **ne détecte pas l'IA**, **ne certifie pas l'originalité** et **ne prouve pas l'auteur unique**.
